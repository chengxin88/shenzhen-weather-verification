# 详细分析改版报告

## 改动的文件

- `index.html`：详情页重新排版，左侧新增「要素 → 指标」树；筛选区压成一行卡片；移除旧标签页、指标按钮行和重复的检验对象切换条；加入移动端指标下拉框。
- `app.js`：按「一指标一页」重写详情页控制与渲染；主图改为“指标 × 预报时效”多模式折线；日期/时次/累积/阈值/站点参考/模式筛选；模式 × 时效表、加粗规则、CSV/SVG 导出；评分综合图小多图；说明页；旧 hash 兼容。
- `grid-stations.js`：站点分布改成独立页面，仍复用原来的地图缩放、站点点击、单站预报/实况卡片；去掉重复的指标/阈值控件，改用页面状态；新增地图模式与单站时效选择。
- `style.css`：新导航、单行筛选、图/表、小多图、移动端下拉框与窄屏布局；表格只在容器内横向滚动。

没有改 `overview.js`，没有改任何评分 Python、缓存格式或后端接口。

## 页面前后对比（文字）

改版前：进入「降水/气温/地面/环流」后，上方是一整排指标按钮，下面还有「多模式对比 / 单模式检验 / 时效对比 / 时效 × 阈值 / 时间序列 / 评分综合图 / 资料与口径」七个标签页；日期、累计、时次、阈值、有效时刻、共同时间、分级、单模式等控件分散在多行，用户需要先理解这些概念才能看图。

改版后：左侧先选要素，再选一个指标，一个指标直接是一页。顶部只保留日期（近 3/7/30 天）、起报时次（全部/08/20）、累积（仅降水）、阈值（仅需要时）、检验对象（站点/格点）和模式芯片。主图固定为“指标随预报时效”的多模式折线，选了单一 08/20 时次时横轴下方再标对应北京检验时刻；图下同一份数据变成“模式 × 时效”表，每列最好值加粗，缺测显示「—」，悬停可看样本数。图标题旁只有「随预报时效 | 随日期」两态切换和一个固定时效下拉，不再有单独的时效选择器。降水另有「评分综合图」，按阈值拆成并排两张/多张小图。菜单末尾是「站点分布」和「说明」。

## 删掉的控件/视图

- 图上方整排指标按钮（`#metric-switch`）和「预报时效」选择器/快捷键。
- 七个标签页：多模式对比、单模式检验、时效对比、时效 × 阈值、时间序列、评分综合图（保留为指标页）、资料与口径（改为「说明」）。
- 检验方式（累加/分级）、仅共同有效时次、各时效同一组有效时间、单模式选择、有效时刻选择器：不再显示；默认沿用原默认值（共同有效=开、跨时效同一组=关、检验方式=累加），口径写在「说明」里。若所选模式没有共同有效时次，图表自动按各自有效时次显示，并在图注中说明。
- 重复的「检验资料 格点/站点」横条（`#grid-source-bar`）；站点/格点切换并入筛选行。
- 地面要素的独立「检验要素」按钮组；改为菜单里的地面气压/10 米风/100 米风分组。
- 原来环流/地面的多参考资料按钮行：改为仅在确实存在多份参考资料时出现的一个下拉，避免丢失参考资料选择。
- 「今天 / 全部资料」日期快捷；只保留近 3/7/30 天。
- 站点的重复指标/阈值芯片（地图卡内）；地图使用当前指标页和筛选阈值。

## 尚未做的 / 需要后端的需求

- **分级检验**：详细分析暂不提供分级页，只在「说明」中说明可在考核总览看分级 TS。若要在详情页做，需要把分级计数和阈值选择重新组织成页面，代价较大。
- **日期口径**：日期仍按现有**有效时间**筛选，和考核总览、站点地图、`/api/stations/grid-rows` 的日期参数一致。若改成严格按“起报日期”筛选，需要同时改站点地图/单站接口的后端日期过滤，本次未做；图中同时标出所选样本的实际起报日期范围。
- **站数**：标题显示区域/资料范围，没有显示精确站数。现有详细页接口不按区域返回站数，考核总览的 `station_count` 也没有复用；没有为显示站数额外加请求或伪造数字。
- 站点分布页的指标/阈值现在跟随左侧指标页和筛选行；地图卡内不再有独立指标芯片。
